# Exploratory Data Analysis in Python

A collection of EDA projects analyzing real-world datasets using Python.

## Tools Used
- Python
- Pandas
- Numpy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Projects
| Project | Dataset | Key Findings |
|--------|---------|--------------|
| Sales Data Analysis | Sales Data | Karachi had the highest return rate among all regions • Salespersons with high revenue but high returns are not true top performers — net revenue tells the real story • Discounts above 10% did not always lead to higher units sold |
| PSL Data Analysis | PSL 2022 Match Data | Toss winner only wins the match ~44% of the time — toss is not a big advantage • Most matches were won by Runs rather than Wickets • Gaddafi Stadium Lahore hosted the most matches • Average first innings score was ~166 runs |
